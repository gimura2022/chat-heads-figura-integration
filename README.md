# Chat Heads Figura Integration
> [!WARNING]
> This mod is currently in the beta testing stage and contains some visual bugs.

This small client-side mod integrates [Figura](https://modrinth.com/mod/figura) avatar head rendering into the [Chat Heads](https://modrinth.com/mod/chat-heads) mod.
Currently, the mod supports Minecraft version 1.21.8, Figura version 1.5, and Chat Heads version 0.14.2.
